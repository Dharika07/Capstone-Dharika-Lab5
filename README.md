# Foodie - Food Delivery App

**Theme:** Food Delivery App
**Project:** HTML5 + CSS3 Capstone (Lab 5)

A fully responsive, semantic static website for a food delivery app, built using only HTML5 and CSS3.

## Sections Implemented
- **Header:** logo, navigation links, Login and Sign Up buttons
- **Hero:** heading, tagline, "Order Now" button and food image
- **Search Form:** location input and category dropdown
- **Browse by Category:** Pizza, Chinese, Burger, Sushi, Pasta, Dessert, Indian Thali, South Indian
- **Featured Restaurants:** restaurant cards with image, cuisine and rating
- **Promo Offers:** three offer cards
- **Testimonials:** customer reviews with photos
- **Footer:** contact email, social links and copyright

## Techniques Used
- Semantic HTML5 (`header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS Flexbox for header, hero and forms
- CSS Grid for category, restaurant, offer and testimonial layouts
- CSS variables for colors, spacing and shadows
- Google Font: Poppins
- Hover effects and smooth transitions (0.2s ease)
- Accessibility: skip link, `aria-label` on navigation, `alt` text on all images, `<label>` for form fields

## Breakpoints
| Screen | Width | Layout |
|---|---|---|
| Desktop | 1024px and above | Multi-column grids |
| Tablet | up to 1024px | 2-column restaurants, 3-column categories |
| Mobile | up to 768px | Single column, stacked header and hero |

## How to Run Locally
1. Download or clone this repository
2. Open `index.html` in any browser
3. Or use the VS Code **Live Server** extension (right-click `index.html` → Open with Live Server)
